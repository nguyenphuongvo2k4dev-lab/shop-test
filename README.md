# ShopVN - React + TailwindCSS

Giao diện trang chủ thương mại điện tử lấy cảm hứng từ bố cục Shopee, phục vụ mục đích học tập/demo.

## Công nghệ
- React 18
- Vite
- TailwindCSS 4
- Lucide React

## Cài đặt

```bash
npm install
npm run dev
```

Sau đó mở địa chỉ Vite hiển thị trong terminal, thường là:
`http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```

## Cấu trúc

```text
shopee-clone-react/
├── public/
├── src/
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

Ảnh demo đang dùng nguồn placeholder `picsum.photos`; có thể thay bằng ảnh sản phẩm thật trong `src/App.jsx`.
